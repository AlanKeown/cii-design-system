title: Patterns
description: Compose components into complete community-service workflows.
---

Patterns document the responsibilities between controls, application state and feedback. They do not add exports to `@cii/svelte`.

| Pattern | Use it for |
| --- | --- |
| [Page heading](/patterns/page-heading/) | Titles, descriptions and primary/secondary actions |
| [Dashboard](/patterns/dashboard/) | Metrics, attention queues, activity and upcoming events |
| [Record forms](/patterns/record-forms/) | Create/edit, validation, drafts and save feedback |
| [Record detail](/patterns/record-detail/) | Overview, activity, notes, relationships and update metadata |
| [Reporting and date ranges](/patterns/reporting/) | Range validation, summary metrics, results and export |
| [Bulk actions and export](/patterns/bulk-actions/) | Selection scope, confirmation and CSV output |
| [Permissions and workspace context](/patterns/permissions/) | Role-aware navigation/actions and demo preview boundaries |

Read the [component catalogue](/components/) for implementation status. Each pattern identifies current portal behaviour separately from its recommended contract.
